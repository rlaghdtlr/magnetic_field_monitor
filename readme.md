# 자계 노출 측정기 모니터링 시스템

## 프로젝트 개요
- 목적: RS-232C 통신을 통해 자계 노출 측정기와 통신하는 시스템 개발
- 개발 언어: Python
- 주요 라이브러리: PyQt5 (GUI), pyserial (시리얼 통신)
- 개발환경: Python 3.10, PyQt5, pyserial

## 설치 방법

### 필수 요구사항
- Python 3.10 이상
- PyQt5 5.15.11 이상
- pyserial 3.5 이상

### 설치 과정
1. 저장소 클론 또는 다운로드
2. 필요한 패키지 설치:
```
pip install -r requirements.txt
```

### 프로젝트 실행
```
python main.py
```

## 프로젝트 구조
```
magnetic_field_monitor/
├── main.py                  # 메인 애플리케이션 진입점
├── requirements.txt         # 필요한 패키지 목록
├── communication/           # 통신 관련 모듈
│   ├── __init__.py
│   ├── serial_connection.py # 시리얼 연결 관리
│   └── protocol.py          # 통신 프로토콜 처리
├── commands/                # 명령 처리 모듈
│   ├── __init__.py
│   ├── command_handler.py   # 명령 처리 관리
│   ├── status_commands.py   # 상태 조회 명령
│   └── control_commands.py  # 제어 명령
├── gui/                     # GUI 모듈
│   ├── __init__.py
│   ├── main_window.py       # 메인 윈도우
│   ├── connection_widget.py # 연결 설정 위젯
│   ├── status_widget.py     # 상태 표시 위젯
│   ├── control_widget.py    # 제어 위젯
│   ├── log_widget.py        # 로그 데이터 위젯
│   └── settings_widget.py   # 설정 위젯
└── utils/                   # 유틸리티 모듈
    ├── __init__.py
    ├── crc.py               # CRC 계산
    ├── logger.py            # 로깅 유틸리티
    └── data_manager.py      # 데이터 관리
```

## 주요 기능

### 1. 통신 모듈
- RS-232C 시리얼 통신 구현
- 시리얼 포트 연결/해제 기능
- 데이터 송수신 기능
- 통신 상태 모니터링
- 프레임 생성 및 파싱 (STX + TYPE + DATA + CRC + ETX)
- CRC-16 계산 및 검증

### 2. 명령 처리 모듈
- 상태 조회 명령
  - 장치 상태 조회
  - 장치 버전 조회
  - 장치 정보 조회
  - 자계 상태 조회
- 제어 명령
  - 자계 활성화/비활성화
  - 자계 강도 설정
  - 자계 주파수 설정
  - 감지 시작/중지
  - 장치 초기화

### 3. GUI 모듈
- 연결 설정 화면
  - 시리얼 포트 설정
  - 통신 매개변수 설정
  - 연결/해제 제어
- 상태 표시 화면
  - 장치 정보 표시
  - 장치 상태 표시
  - 자계 상태 표시
  - 자동 갱신 기능
- 제어 화면
  - 자계 제어 기능
  - 감지 제어 기능
  - 장치 초기화 기능
- 로그 데이터 화면
  - 로그 데이터 표시
  - CSV 내보내기 기능
- 설정 화면
  - UI 설정
  - 로깅 설정
  - 자동 연결 설정

### 4. 유틸리티 모듈
- CRC 계산 및 검증
- 로깅 기능
- 데이터 저장 및 관리
  - 로그 데이터 저장
  - 설정 데이터 저장
  - CSV 내보내기/가져오기

## 사용 방법

### 1. 연결 설정
1. '연결' 탭에서 시리얼 포트 및 통신 매개변수 설정
2. '연결' 버튼 클릭하여 장치에 연결

### 2. 상태 확인
1. '상태' 탭에서 장치 정보 및 상태 확인
2. '상태 갱신' 버튼 또는 '자동 갱신' 기능 사용

### 3. 장치 제어
1. '제어' 탭에서 자계 활성화/비활성화
2. 자계 강도 및 주파수 설정
3. 감지 시작/중지 제어

### 4. 로그 데이터 관리
1. '로그' 탭에서 로그 데이터 확인
2. 로그 파일 로드 및 CSV 내보내기

### 5. 설정 관리
1. '설정' 탭에서 UI, 로깅, 자동 연결 설정
2. '설정 저장' 버튼으로 설정 저장
